# StudyHub - Online Learning Platform

## About
StudyHub is an online learning platform built with Python Django. Students can enroll in courses, watch video lectures, and track their progress. Instructors can create and manage courses.

## Features
- User Login/Register (Student & Instructor roles)
- Browse and search courses
- Enroll in free or paid courses
- Watch YouTube video lectures
- Student dashboard
- Razorpay payment gateway (test mode)
- Dark mode toggle
- Mobile responsive design

## Technologies Used
- Python & Django
- HTML, CSS, Bootstrap, JavaScript
- SQLite (development) / MySQL (production)
- Razorpay API

## Installation

1. Clone the repository
2. Create virtual environment
3. Install dependencies
4. Create .env file and add your keys
5. Run migrations
6. Create superuser
7. Run server
